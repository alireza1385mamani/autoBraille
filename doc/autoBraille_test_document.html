Auto Braille - Comprehensive Feature Test Document

This interactive test suite is designed to test every capability of Auto Braille with NVDA and a refreshable braille display.

Prerequisites for Testing

  1. Auto Braille Settings (NVDA + Control + G → Auto Braille):
    • Primary output table: Choose your primary table (e.g. English (Unified) Grade 1 or Automatic).
    • Active Secondary Tables: Ensure Persian grade 1 (fa-ir-g1.utb) is in the active list (add via Add Table... if needed).
    • Tactile indicator for language boundaries: Select Dot 8 under first cell of language change (or Dots 7 and 8 underline).
    • Honor document language tags: Checked [X].
  2. Caret Language Announcement Shortcut (NVDA Menu → Preferences → Input Gestures → Auto Braille):
    • Assign a gesture (e.g. NVDA + Shift + L) to Announce the language and braille table at the caret or review cursor.

Test 1: In-Line Multi-Script Output Translation (Feature 1)

Tests automatic detection of script boundaries and seamless Liblouis table stitching within a single line.

1.1 Mixed Persian and English in a Sentence

Sentence with alternating Persian and English phrases:

سلام! این یک test برای بررسی ترجمه چند زبانه است.
What to check:
  • "سلام! این یک " should translate via fa-ir-g1.utb (Persian Braille).
  • "test" should automatically translate via en-ueb-g1.ctb (English UEB Braille).
  • "برای بررسی ترجمه چند زبانه است." should seamlessly revert back to Persian Braille.
  • Pressing cursor routing buttons above "test" and Persian words should navigate directly to the correct character.

1.2 Technical Terminology & Code in Mixed Text

برای کامپایل برنامه از دستور python build.py --release استفاده کنید.
What to check: Persian context remains Persian; the terminal command is rendered in English UEB computer braille.

1.3 Numbers and Mixed Punctuation

قیمت محصول 25000 تومان (معادل $0.50 USD) است. شماره تماس: +98 21 1234 5678.
What to check: Numbers, currency symbols, and parenthetical English terms are positioned correctly without braille buffer corruption or misalignment.

Step-by-step test procedure:

Test 4: Smart Document Language Tag Integration (Feature 4)

Tests official HTML lang attribute processing and automatic fallback on inaccurate tags.

4.1 Official Valid HTML Language Tags

These elements contain explicit, correct lang tags:

English Paragraph: lang="en"

This entire sentence is explicitly marked as English in the HTML source code.

Persian Paragraph: lang="fa"

این متن به طور صریح با تگ زبان فارسی علامت‌گذاری شده است.
What to check: NVDA respects the official lang attributes and routes each span directly to its corresponding braille table.

4.2 Inaccurate / Mismatched Document Tag (Automatic Fallback Test)

In this test, the HTML tag claims the text is English (lang="en"), but the actual characters are Persian: Mismatched: lang="en" on Persian characters

این یک متن فارسی است که اشتباها به عنوان انگلیسی تگ شده است.
What to check:
  • Auto Braille's is_script_compatible validator detects that the text contains Persian/Arabic characters that contradict lang="en".
  • It automatically falls back to the Unicode script detector, correctly rendering Persian braille cells instead of garbled English cells!

4.3 Neutral Characters Under Language Tags

Numbers and symbols adopt the document language:

[EN] Code: 98765-ABC, Year: (2026).
[FA] کد: 98765-ABC، سال: (2026).
What to check: Neutral punctuation and numbers are translated with the respective language's punctuation rules.
