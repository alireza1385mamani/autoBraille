Auto Braille: Universal Multi-Script In-Line Translation & Perkins Input for NVDA

Author: Alireza Mamani & Antigravity (<https://github.com/alireza1385mamani>) | Repository: <https://github.com/alireza1385mamani/autoBraille>

Compatibility: NVDA 2024.1 to 2026.3+ | License: GNU General Public License v2.0

Key Features

  • In-Line Multi-Script Output Translation: Automatically detects distinct writing systems (Arabic/Persian, Cyrillic, Hebrew, Greek, Indic, CJK, Latin) and translates each segment with its designated Liblouis table in-line.
  • Perkins Braille Input Auto-Switching: Automatically synchronizes the braille keyboard input table with the active Windows keyboard layout in real time.
  • Tactile & Spoken Boundary Indicators: Optional Dot 8 or Dot 7 pin indicators at language transitions, or continuous Dots 7 & 8 underline under secondary language text.
  • Announce Language at Caret: Shortcut speaking and flashing the character, language, and Liblouis table on the braille display.
  • Document Language Tag Integration: Respects official HTML/Word lang tags with automatic script compatibility validation and fallback.

Settings

Open NVDA Settings (NVDA + Control + G) → Auto Braille to configure:

  • Master translation and input synchronization toggles.
  • Document language tag honoring.
  • Tactile indicator for language boundaries.
  • Primary output and Perkins input braille tables.
  • Active Secondary Braille Tables list (Add Table, Configure Table, Remove Table).

Input Gestures

Available under NVDA Menu → Preferences → Input Gestures → Auto Braille:

  • Toggles automatic universal multi-script braille translation on and off.
  • Cycles or toggles Perkins braille keyboard input language.
  • Announces the language and braille table at the caret or review cursor.
