Auto Braille: Universal Multi-Script In-Line Translation & Perkins Input for NVDA

Version: 1.0.4 | NVDA Compatibility: 2024.1 to 2026.3+ | License: GNU General Public License v2.0

Author: Alireza Mamani & Antigravity (<https://github.com/alireza1385mamani>)
Repository: <https://github.com/alireza1385mamani/autoBraille>

Auto Braille is an open-source NVDA global plugin that brings seamless multi-lingual braille output and intelligent Perkins keyboard input auto-switching to every refreshable braille display supported by NVDA.

Key Features

1. In-Line Multi-Script Output Translation

  • Automatically detects distinct writing systems (Arabic/Persian, Cyrillic, Hebrew, Greek, Indic including Sinhala, East Asian CJK, Southeast Asian, Caucasian including Georgian and Armenian, and Latin) in any line of text.
  • Dynamically routes each language segment to its dedicated Liblouis table (e.g. fa-ir-g1.utb for Persian, ar-ar-g1.utb for Arabic, and en-ueb-g1.ctb for English).
  • Stitches braille cells together seamlessly in real time with sub-microsecond C-level regex execution and full cursor routing accuracy.

2. Bi-Directional Perkins Braille Keyboard Auto-Switching

  • Real-time synchronization between the active Windows keyboard layout (e.g. Persian 0x0429 vs. English 0x0409) and the Perkins braille input table.
  • Press Alt + Shift or Windows + Space anywhere in Windows — your Perkins braille keyboard updates instantly without navigating nested menus.

3. Tactile & Spoken Boundary Indicators (Optional)

  • Tactile Pin Indicators: Subtly feel language transitions on 8-dot braille displays:
    • Dot 8 under first cell of language change (Recommended): Raises pin 8 under the first cell when text switches languages.
    • Dot 7 under first cell of language change: Raises pin 7 under the first cell when text switches languages.
    • Dots 7 and 8 underline under secondary language cells: Continuously underlines secondary language text with pins 7 and 8.
  • Announce Language at Caret: Press your assigned gesture (e.g. NVDA + Shift + L) to simultaneously hear and feel the active character, specific language name, and Liblouis table on the display.

4. Smart Document Language Tag Integration (lang tags)

  • In web browsers (Chrome, Edge, Firefox) and Office applications (Word, LibreOffice), official document language markup (such as <span lang="fa">, <span lang="ar">, <p lang="fr">) is automatically detected and respected.
  • Script Compatibility Guard: If text is mislabeled with an incompatible tag, Auto Braille automatically validates the characters and falls back to the Unicode script detector so your braille is never garbled.

5. Contracted Braille (Grade 2) Support & Boundary Guarding

  • Full Grade 2 Support: Configure any table to use Contracted Braille (e.g. en-ueb-g2.ctb, ar-ar-g2.ctb, de-g2.ctb).
  • Single-Letter Word-Sign Protection: In Grade 2 UEB, isolated letters contract to whole words (b = "but", c = "can", x = "it"). Auto Braille automatically routes isolated single letters flanked by foreign text or punctuation (e.g. گزینه b, کلید c) through an uncontracted Grade 1 companion table.
  • Code & Identifier Protection: Technical identifiers (such as user_id, file_name, camelCase, or file paths) are protected from literary contractions so you can read and debug code accurately.
  • Numeric Boundary Lookback: Letters immediately following digits across boundaries (e.g. 123b) are shielded from digit-letter contraction bleed.

6. 3-Tier Multi-Language Architecture & Loanword Stability

  • Zero Flapping on Loanwords: Persian words with Arabic letters (such as دایرة‌المعارف, نهایة) and English words with accents (café, résumé) remain stably in their native table.
  • Intra-Script Disambiguation: When both Persian and Arabic, or English and French/German tables are active, multi-word grammatical clauses (such as قال المعلم: في التأني السلامة) are automatically routed using grammatical stop-word phrase density.
  • Dynamic Secondary Defaults: If your primary NVDA table is Persian, Arabic, or Russian, Auto Braille automatically defaults its secondary table to English UEB out of the box.

7. One-Click Setup Wizard (Auto-Detect Windows Keyboards)

  • Instant Automatic Setup: Click Auto-Detect Keyboards... in settings to scan your installed Windows keyboard layouts.
  • Smart Liblouis Mapping: Matches each keyboard to its recommended braille output and Perkins input table, while preserving your primary language and eliminating duplicate dialects.
  • In-Place Customization: Select any detected candidate and click Edit Table... to customize its output or Perkins input table before applying.

Configuration

Security Notice: In compliance with official NVDA Add-on Store standards, the configuration panel is safely disabled when NVDA runs on the Windows Secure Desktop (e.g. UAC elevation prompts and login screens).

Open NVDA Settings (NVDA + Control + G) → Auto Braille to configure:

  • Enable automatic multi-language braille output translation: Master toggle for in-line multi-script translation.
  • Automatically sync Perkins braille input with active Windows keyboard layout: Master toggle for real-time Perkins input table switching.
  • Honor document language tags in web and office documents: Prioritize official HTML/Word lang tags when accurate.
  • Protect isolated letters and code identifiers in Contracted Braille (Grade 2): Safeguards single-letter variables and technical identifiers against accidental contractions.
  • Tactile indicator for language boundaries: Select your preferred pin indicator (None, Dot 8, Dot 7, or Dots 7 and 8 underline).
  • Primary output braille table: Select your default output table from all installed Liblouis tables, or choose Automatic (Use active NVDA output table).
  • Primary Perkins input braille table: Select your default Perkins input table, or choose Automatic (Follow active NVDA input table).
  • Active Secondary Braille Tables List: Click Add Table... to activate any secondary braille table manually, or click Auto-Detect Keyboards... to instantly configure all installed Windows keyboard languages.

Input Gestures

Available under NVDA Menu → Preferences → Input Gestures → Auto Braille:

  • Toggles automatic universal multi-script braille translation on and off: (Unassigned by default).
  • Cycles or toggles Perkins braille keyboard input language: (Unassigned by default).
  • Announces the language and braille table at the caret or review cursor: (Recommended shortcut: NVDA + Shift + L or a key on your braille display).
